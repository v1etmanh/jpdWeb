# AI for SE - Course Management feature

## Mô tả Dự án

Dự án này là một phần của website tự học ngôn ngữ, tập trung vào việc viết Unit Test cho các chức năng "Quản lý Khóa học" (Course Management) trong `CourseService`.

## Yêu cầu Cài đặt

Trước khi bắt đầu, hãy đảm bảo bạn đã cài đặt:

* **Java JDK:** 21
* **Spring Boot:** 3.5.x
* **Build Tool:** Maven (phiên bản 3.8.x trở lên)

## Cách chạy Tests

1.  Clone repository này về máy của bạn.
2.  Mở terminal và điều hướng đến thư mục gốc của dự án.
3.  Chạy lệnh sau để build dự án và thực thi tất cả các unit test:

    ```bash
    mvn clean test
    ```
